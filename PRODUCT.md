# Product

## Purpose

The AI Receptionist is a business system that acts as an AI front desk: it should answer incoming calls, understand customer requests, answer questions from business-provided information, collect customer details, and handle requests such as orders, bookings, and appointments. It should turn conversations into real business actions and useful conversation/activity records, reducing missed calls and repetitive manual work.

## Current state

The project is a sales-oriented React demo: a marketing landing page, sample call and order visuals, and a dashboard populated with static example conversations and activity. The dashboard talk control is a visual toggle; there is no live voice, authentication, business data, or action workflow connected yet. The Vapi endpoint is a basic POST acknowledgement.

## Planned state and priority

The initial product is a convincing demo/MVP that makes the business value easy to understand and helps win a paying client. Build only what supports that outcome. The sequence is:

**Demo → demonstrate business value → get a paying client → build the production version → productize later.**

The first production path should prove a narrow receptionist workflow for a real business before expanding into a broad SaaS platform. Prioritize reliable call handling, accurate business answers, useful information capture, real actions, and clear records of what happened.
